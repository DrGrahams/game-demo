# 余光

> 在暗区吞没一切之前，抓住最后一道余光。

一款以「电条即生命」为核心机制的 Roguelike 卡牌构筑游戏。玩家在废土地图上逐层推进，通过时间轴回合制战斗收集卡牌、强化构筑，最终击败关底 Boss。UI 主要采用 C# 代码动态构建，核心玩法逻辑由代码实现，减少对预制体与场景引用的依赖。

## 核心玩法

### 核心循环

```
标题界面 → 进入地图 → 选择节点 → 战斗 / 休整 / 事件 → 卡牌奖励 → 回到地图 → ... → 击败 Boss → 单局结束
```

一张「单局」(Run) 包含 14 层、48 个节点的分支地图。玩家从底部起点出发，每层选择一个可达节点前进，最终抵达顶部 Boss 层。

### 战斗系统：PEAK 电条 + Tick 时间轴

战斗建立在自定义的 **「PEAK 电条」生命模型** 与 **「刻」(Tick) 时间轴** 上：

- **电条即生命**：`Capacity`（容量=最大生命）、`Dark`（暗区=永久损伤，从右端生长）、`Storage`（亮区=行动资源）。暗区吃穿整条即死亡。
- **刻驱动回合制**：每张卡牌有耗时（若干刻）+ 资源消耗。出牌后时间轴推进，沿途结算敌人事件。同一刻内**先结算玩家效果、再结算敌人事件**——这一顺序是蓄力打断等机制成立的基础。
- **伤害结算链**：敌人打击 → 临时盾优先抵扣 → 漏过伤害 1:1 进暗区（不扣存量）→ 暗区 ≥ 容量即死亡。木材掠夺则先扣木材、缺口转化为暗区。
- **时间轴可视化**：玩家可在 UI 上预读未来若干刻的全部敌人事件（伤害数字、掠夺、蓄力黄条），决策本质是「读时间表出牌」。

### 节点类型

| 类型 | 颜色 | 功能                            |
| -- | -- | ----------------------------- |
| 战斗 | 红  | 进入回合制战斗，胜利后弹出卡牌三选一奖励          |
| 休整 | 绿  | 二选一：修复 2 点暗区 / 锻造升级一张卡牌       |
| 事件 | 紫  | 二选一：电量上限 +1 / 初始木材 +2（单局永久叠加） |
| 首领 | 橙  | 关底 Boss 战，胜利即单局结束             |

事件节点和休整节点可分布在同一层——同层只能走一个节点，变相限制此类收益的获取数量。

### 卡牌系统

- **初始牌组** 5 张：等待、采集木材、手摇发电、矛掷、格挡
- **奖励池** 7 张进阶卡：重击、修复、嗜血、过载放电、蓄力一击、木材发电机、电池
- 每场战斗胜利后从奖励池随机抽三张供三选一（可跳过），每张进阶卡每单局仅可获得一次
- 牌组上限 8 张，满编后选新卡进入替换模式：选一张旧卡移除确认
- 卡牌有 2 级制，休整节点可锻造升级（如矛掷 6→8 伤），升级后卡名带 "+"
- 出牌时有资源与可行性校验，悬停预览执行后的资源/伤害增量

### 单局级状态管理

单局内有四类状态跨战斗保留，构成「永久代价 vs 局内资源」的双层节奏：

| 状态             | 跨战斗保留 | 说明                           |
| -------------- | ----- | ---------------------------- |
| 牌组             | ✅     | 每场战斗后增长/替换，单局内持续构筑           |
| 暗区损伤           | ✅     | 永久代价，单局内累积不可逆（仅 Rest 可修复）    |
| 光屑货币           | ✅     | 单局货币常驻显示                     |
| 事件加成           | ✅     | 电量上限 +1 / 初始木材 +2，可跨多个事件节点叠加 |
| 电存量 / 木材 / 临时盾 | ❌     | 每场战斗重置（半血进场）                 |

### 敌人设计

敌人没有反应式动态 AI，而是**可预读的预设时间轴**——每种敌人有固定的事件脚本（打击/掠夺/蓄力），33 刻后进入无限递增段：

| 敌人         | 定位   | 核心机制                                            |
| ---------- | ---- | ----------------------------------------------- |
| 游荡者        | 教学基础 | 打击 + 木材掠夺交替，慢递增                                 |
| 铁壳兽        | 血线压力 | 纯打击不掠夺，快递增（间隔 2 刻）                              |
| 拾荒鸦        | 资源博弈 | 打掠循环，每次掠夺给下一击附 +2 单次强化（狠咬/裸咬节奏）                 |
| 野蛮领主（Boss） | 机制考试 | 三轮蓄力重炮 10/12/14，蓄力 3 刻窗口内被任意攻击牌命中即溃散为 3/4/5 小伤害 |

野蛮领主的蓄力打断机制：打断钩子统一埋在 `EnemyState.TakeDamage()` 中，所有攻击牌自动获得打断能力，无需为每张卡单独写打断逻辑。时间轴 UI 上蓄力期间显示黄色区间条，打断后即时变灰。

**战斗内部协作**：

```
玩家出牌 → CombatManager.ExecuteAction()
  → 资源校验（PlayerState）
  → 效果执行（GameAction.DoAction）
  → 时间轴推进（TickTimeline.Advance）
    → 逐刻结算敌人事件（TimelineEvent）
      → Strike: EnemyState → PlayerState.TakeStrike（盾→暗区）
      → Plunder: PlayerState 木材扣减 → 暗区转化
      → ChargeStart: EnemyState.BeginCharge()
      → Ultimate: 按 ChargeInterrupted 取满额/溃散伤害
    → 同刻先玩家后敌人
  → 胜负判定（Dark ≥ Capacity = 败 / 敌 HP ≤ 0 = 胜）
  → CombatUIController 刷新全部 UI
```

### 五大核心系统

**1. 地图系统** — `MapData` + `MapUIController`

- 数据层负责节点/边/可达性校验与地图渲染数据。当前版本使用预设地图保证流程稳定；另保留一套随机生成管线（层宽生成 → 连通性修复 → 消交叉 → 坐标归一化），暂未作为正式版本启用
- 渲染层用 ScrollRect 渲染节点、连线、类型配色与点击交互，进入时播放从 Boss 端滑到起点层的缓动动画
- 14 层波峰曲线、固定 3 个 Rest 节点（分布跨 3 个非连续层）、8 个 Event 节点（3 个与 Rest 同层形成二选一博弈）

**2. 战斗系统** — `CombatManager` + `PlayerState` / `EnemyState` + `TickTimeline`

- CombatManager 编排刻推进与同刻结算（玩家效果先于敌人事件）
- PlayerState 持有 PEAK 电条四元组（Capacity / Dark / Storage / TempShield）
- EnemyState 持有蓄力状态机（IsCharging / ChargeInterrupted），打断钩子在 TakeDamage 中统一触发
- TickTimeline 持有敌人事件脚本与无限递增段，支持自定义 S/R 模式循环

**3. 卡牌系统** — `GameAction` + `ActionDatabase` + 12 张实现

- GameAction 基类定义：唯一 Id、名称、分类、资源消耗、耗时刻数、效果描述、等级
- ActionDatabase 管理初始牌组、奖励池、图鉴数据源三个集合
- 每张卡牌是独立实现类，通过 DoAction() 执行效果

**4. 界面系统** — 8 个代码构建的 UI 控制器

- 主要采用 C# 代码动态构建（无预制体），通过 `[RuntimeInitializeOnLoadMethod]` 自动创建
- CanvasScaler 统一 `ScaleWithScreenSize + 1920×1080 + match=0`（以高度为基准）：逻辑高恒 1080，纵向布局跨 16:9 / 16:10 / 21:9 一致；横向宽度随屏幕比例变化，固定宽度元素按面板实际可用宽自适应
- 行动区 GridLayout 幂等刷新布局参数（不销毁重建按钮），避免重建循环与残留

**5. 单局编排系统** — `GameBootstrap`

- 持有跨战斗状态（RunDeck、\_runDark、光屑、电量/木材事件加成）
- 订阅战斗胜负和各 UI 回调，驱动「地图→战斗→奖励→地图」状态机
- 节点分流：Battle 进战斗、Rest/Event 弹出对应选项 UI、Boss 通关结束单局
- 标题界面 → 开始游戏 → ESC 暂停（继续/返回标题/退出游戏）完整流程闭环

## 技术实现细节

| 亮点              | 说明                                                                                                     |
| --------------- | ------------------------------------------------------------------------------------------------------ |
| **代码构建 UI**     | UI 主要采用 C# 代码动态构建（无 Prefab 引用），仅依赖字体资源，可移植性高                                                           |
| **跨分辨率自适应**     | CanvasScaler 以高度为基准（match=0）：逻辑高恒 1080，纵向布局跨 16:9 / 16:10 / 21:9 一致；横向宽随比例变化，固定宽度元素（卡牌网格）按面板实际可用宽自适应计算 |
| **PEAK 电条生命模型** | 将「生命值」「行动资源」「永久损伤」「临时盾」统一到一条电条上，伤害结算链清晰，无需传统 HP 数字                                                     |
| **时间轴可预读战斗**    | 敌人行为是预设时间轴而非黑盒 AI，玩家可预读未来事件做资源规划，策略性高于反应式战斗                                                            |
| **蓄力打断机制**      | 打断钩子埋在 EnemyState.TakeDamage 统一入口，所有攻击牌自动获得打断能力，零改动行动牌代码                                               |
| **地图生成管线**      | 预设地图保证流程稳定；同时保留随机生成管线（层宽生成→窗口单调连线→连通性修复→消交叉→坐标归一化），当前未作为正式版本启用                                         |
| **单局级双层状态**     | 永久代价（暗区/牌组/事件加成）跨战斗保留 vs 局内资源（电量/木材/盾）每场重置，构成「长线规划 + 短线操作」节奏                                           |
